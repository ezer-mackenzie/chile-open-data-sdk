# Chile Open Data SDK

An unofficial community Python SDK for datos.gob.cl and compatible CKAN sites.
It is not an official SDK of the Government of Chile or portal maintainers.

**v0.2.0** adds typed catalog discovery and lazy dataset pagination to the
synchronous foundation. Discover datasets, resources, organizations, groups, and
tags through dedicated services, preserving plugin metadata. DataStore wrappers,
async clients, retries, and dataframe integrations remain future milestones.

Start with [Getting started](getting-started.md), then review
[Catalog discovery](catalog.md), [Generic actions](actions.md), [Configuration](configuration.md), and
[Error handling](errors.md). The [API reference](api.md) is generated from the
implementation's signatures and docstrings.

See [Compatibility](compatibility.md) for limits and [Roadmap](roadmap.md) for
later milestones. Maintainers should follow the [release process](releasing.md)
and review the [validation record](release-validation.md) before publishing.
